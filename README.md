# 上関原発ドキュメント

公開サイト: https://kaminoseki-doc.github.io/

山口県上関町の原子力発電所計画と使用済み核燃料中間貯蔵施設計画について、経緯、選挙の記録、公開資料、賛否の論点を整理する非公式の情報サイトです。自治体・事業者の公式サイトではありません。

## 編集方針

- 事実、事業者・行政の評価、賛否それぞれの意見を区別します。
- 選挙結果、町の受け入れ判断、事業計画、許認可、操業開始は別の事項です。
- 一次資料への直接リンクと、公表日・対象時点を優先します。事業者の報告書は「事業者による調査・評価」と明示します。
- 過去の選挙・議会・計画の経緯は対象年月を付けて残します。
- 確認できない事項は断定せず、資料への記載と独立した検証を区別します。
- 国籍や土地の所有だけを根拠に、個人・地域の危険性や違法性を推測しません。

## 掲載内容と確認範囲

2026年10月5日の更新案では、10月4日町長選の公式結果、事業者公表資料、自然公園の規制、周辺断層の研究と事業者評価を整理しています。笠佐島の土地利用・安全保障の議論は、国会答弁の訂正を含め、上関の技術的立地可能性調査とは別の地域論点として扱います。

更新日は、過去の全記述を同日に全面再検証したことを意味しません。人口構成、町議選当選者・候補者アンケートなどは記載時点の記録です。全国の使用済み燃料保管量、再処理工場の完成目標、最終処分の調査状況などは最新の公表資料で再確認が必要です。

## 読み方

「現在地 → 経緯 → 施設の仕組みと論点 → 資料」の順に読めます。選挙の集計、過去の議会・人口データ、規制の細部は見出しを開いて確認できます。笠佐島の話題は関連する地域の議論として別にまとめています。

## ファイル構成

- `index.html`: 本文、CSS、図表を含む単一の静的HTML。
- `README.md`: この説明書。

パッケージ管理・ビルド・自動テスト・GitHub Actionsの設定はありません。Google Fontsを外部から読み込むため、オフラインでは代替フォントになる場合があります。

## 手元で確認する

ビルドは不要です。`index.html` をブラウザで開けます。ローカルファイルを許可しない環境では、許可されたHTTPサーバーを利用してください。Python 3が利用できる場合、リポジトリのディレクトリで:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000/` を開きます。外部公開用の手順ではありません。

## 更新時の確認

1. 元資料の公表日・対象期間・発行主体・該当ページを確認します。
2. 新しい事実を関連箇所に反映し、過去の記録には日付を付けます。
3. 更新段落に直接の出典リンクを付け、未確認事項を確定済みと書かないでください。
4. 更新日と、今回確認した範囲を見直します。
5. PC・スマートフォン相当の幅、明暗表示、ページ内リンク、表、外部リンク先を確認します。
6. `git diff --check` と差分全体をレビューします。

公開前にはGitHub Pagesの配信元と公開手順をリポジトリ設定で確認してください。このREADMEは特定ブランチへのpushだけで公開されることを保証するものではありません。
